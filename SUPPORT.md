# Support

## Getting Help

If you need help with mcp-openapi-proxy, please use the following resources:

- **FAQ:** Check the [FAQ.md](FAQ.md) for answers to common questions, troubleshooting diagnostics, and validation issues.
- **Contributing Guide:** See [CONTRIBUTING.md](CONTRIBUTING.md) for onboarding, validation, and diagnostics steps.
- **Security:** For vulnerability reports and security best practices, see [SECURITY.md](SECURITY.md).
- **Code of Conduct:** All interactions are governed by the [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Community Support

- **GitHub Issues:** Open an issue for bugs, feature requests, or questions not covered in the documentation.
- **GitHub Discussions:** Start a discussion for general questions, feedback, or to connect with other users and contributors.
